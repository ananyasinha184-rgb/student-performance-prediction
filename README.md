
# Student Performance Prediction

A Machine Learning project that predicts student academic performance using study hours, attendance and marks.

## Features
- Student Performance Prediction
- Machine Learning using Decision Tree Classifier
- Flask Web Application
- Analytics Dashboard
- Total Student Statistics
- Average Marks and Attendance
- Performance Distribution Chart
- Average Marks by Category
- Study Hours vs Marks Visualization

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- JavaScript

## Project Structure
- app.py - Flask application
- train_model.py - Model training
- student_model.pkl - Trained ML model
- students.csv - Student dataset
- templates/ - HTML files
- static/ - CSS files

## How to Run

1. Install Python.
2. Install dependencies:

   pip install flask pandas numpy scipy scikit-learn

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000/
